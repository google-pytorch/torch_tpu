GitHub token (optional): raises the search limit from 10 to 30 per minute

Without a token, GitHub allows 10 searches per minute, possibly shared with others on your network. With a personal token, you get 30 per minute of your own. To create one:

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Give it a name (e.g. "TorchTPU dashboard") and an expiration. Leave Repository access as Public repositories and don't add any permissions; read-only access to public data is all the dashboard needs.
  3. Click Generate token, copy it, and paste it below.

The token is kept only in this browser tab's memory and is sent only to api.github.com. It is never saved, so paste it again after you reload the page.
