# TorchTPU Documentation Source

These files are Marimo `.py` notebooks. They serve as the single source of truth
for TorchTPU documentation and tutorials. Jupyter notebooks (`.ipynb`) and
Markdown exports are generated from these files using `publish_notebook.py`.

They can be run directly from a Google Compute Engine (GCE) TPU VM (e.g. `marimo
run <file>.py` or `marimo edit <file>.py`).
