# TorchTPU Public APIs

This page lists all public TorchTPU APIs: the Python APIs and environment
variables that you can use in your programs.

**Warning:** Using any other TorchTPU API is undefined behavior and unsupported.

The PyTorch APIs that TorchTPU implements for TPUs, e.g. `torch.accelerator`,
are documented by PyTorch.

Each public API is in one of the stages below, as defined by the
[TorchTPU API policy](../developers/api_policy.md).

## Internal APIs

Some internal APIs are in a public namespace for PyTorch to call, but they
aren't meant to be used directly. They may change or be removed at any time
without a deprecation process. Calling one from your code raises an error. Use
its recommended alternative instead.

Each API below is internal in the PyTorch versions that provide its recommended
alternative: PyTorch 2.11 or later for the `torch.accelerator` APIs, and PyTorch
2.13 or later for the `torch.accelerator.random` APIs. In the rare case that you
use an older PyTorch version, the API is experimental instead, and you can call
it.

<!-- BEGIN GENERATED: Internal APIs -->

*   `torch.tpu.current_device`: use `torch.accelerator.current_device_index`
    instead
*   `torch.tpu.current_stream`: use `torch.accelerator.current_stream` instead
*   `torch.tpu.device`: use `torch.accelerator.device_index` instead
*   `torch.tpu.device_count`: use `torch.accelerator.device_count` instead
*   `torch.tpu.get_rng_state`: use `torch.accelerator.random.get_rng_state`
    instead
*   `torch.tpu.initial_seed`: use `torch.accelerator.random.initial_seed`
    instead
*   `torch.tpu.is_available`: use `torch.accelerator.is_available` instead
*   `torch.tpu.set_device`: use `torch.accelerator.set_device_index` instead
*   `torch.tpu.set_stream`: use `torch.accelerator.set_stream` instead
*   `torch.tpu.synchronize`: use `torch.accelerator.synchronize` instead
